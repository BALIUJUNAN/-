【开篇：你的角色是什么？】

你现在是超市的"营销总监"，负责让顾客愿意来、多花钱、成为忠实客户。
你的工具箱里有：会员体系、促销活动、套装商品、批次管理、储值卡。

marketing.c 是整个系统中最大的文件（约2600行），因为它合并了五个子模块。
就像一个部门里有五个小组，各干各的活，但都属于"营销"这个大方向。


================================================================================
第一关：会员管理 —— 让顾客变成"自己人"
================================================================================

【生活类比：超市的会员卡】

你去超市，收银员问："有会员吗？" 你说"有"，报手机号，就能打折、攒积分。
这就是会员系统的作用：留住顾客，让他们反复来消费。

【会员数据存在哪？】

- member.txt：会员基本信息
  格式：会员ID|手机号|姓名|等级|积分|累计消费|创建时间|更新时间|上次消费时间

- 内存中用链表 g_members 存所有会员，用哈希表 g_member_phone_hash 通过手机号快速查找

【核心函数详解】

1. add_member(手机号, 姓名) —— 注册新会员
   - 检查手机号是否已注册（通过哈希表O(1)查找）
   - 分配新会员ID（独立计数器，从1开始递增）
   - 初始等级为普通会员，积分为0
   - 插入哈希表和链表
   - 保存到文件

2. find_member_by_phone(手机号) —— 查找会员
   通过哈希表直接查找，速度极快。
   就像你报手机号，收银员在系统里一搜就出来了。

3. get_member_discount(会员) —— 根据等级返回折扣率
   普通会员：不打折（1.00）
   银卡会员：98折（0.98）
   金卡会员：95折（0.95）
   钻石会员：9折（0.90）

4. get_member_level(会员) —— 根据累计消费判断等级
   累计消费 >= 20000元 → 钻石会员
   累计消费 >= 5000元 → 金卡会员
   累计消费 >= 1000元 → 银卡会员
   其他 → 普通会员

5. add_points(会员, 金额) —— 增加积分（阶梯制度）
   这是最有趣的部分！积分不是简单的"1元=1分"，而是阶梯式的：
   - 消费100元以下：1元 = 1积分
   - 消费100-500元的部分：1元 = 2积分
   - 消费500-1000元的部分：1元 = 3积分
   - 消费1000元以上的部分：1元 = 5积分

   举例：你消费了800元
   - 前100元：100 × 1 = 100积分
   - 100-500元部分：400 × 2 = 800积分
   - 500-800元部分：300 × 3 = 900积分
   - 总计：100 + 800 + 900 = 1800积分

   设计意图：鼓励大额消费，买得越多，积分效率越高。

6. redeem_points(会员, 积分数) —— 积分兑换
   100积分 = 1元。最少需要100积分才能兑换。
   就像集点卡——集够了才能换礼品。

7. upgrade_member_level(会员) —— 自动升级
   每次消费后，系统自动检查累计消费是否达到升级门槛。
   达到了就自动升级，就像游戏里的"升级"。


================================================================================
第二关：促销管理 —— 让顾客觉得"赚到了"
================================================================================

【生活类比：超市里的各种促销牌】

你逛超市，看到：
- "可乐原价3.5，现价2.9！"（单品折扣）
- "满100减20"（满减）
- "第二件半价"（第N件优惠）
- "买二送一"（买M赠N）
- "会员专享价2.5元"（会员专属价）

这些促销活动背后都是代码在计算。

【促销的数据结构（Promotion）】

每种促销类型用不同的字段：
- type：促销类型（1-5）
- product_id：针对哪个商品（满减促销不指定商品）
- discount_value：折扣值（单品折扣用0.85表示85折，满减用20表示减20元）
- min_quantity：最低购买数量（第N件优惠用）
- buy_quantity / get_quantity：买M赠N的参数
- priority：优先级（数字越大越优先）
- start_time / end_time：活动有效期

【核心函数详解】

1. create_promotion(促销信息) —— 创建促销活动
   按优先级插入链表（优先级高的排前面）。

2. is_promotion_valid(促销) —— 检查促销是否有效
   - 状态必须是"生效中"
   - 当前时间必须在开始时间和结束时间之间

3. apply_promotions(购物车, 会员) —— 核心：计算所有折扣
   这是整个促销系统的"大脑"。遍历购物车的每个商品，依次检查：

   a) 有没有单品折扣？有就应用
   b) 有没有第N件优惠？比如"第二件半价"，第二件的价格减半
   c) 有没有买M赠N？比如"买2送1"，把第三件的价格设为0
   d) 有没有会员专属价？有就用会员价替换原价
   e) 叠加会员等级折扣（银卡98折等）
   f) 最后检查满减：如果购物车总额达到门槛，再减一笔

   注意：不是所有折扣都能叠加，系统会按优先级选择最优方案。


================================================================================
第三关：购物车 —— 中间的"缓冲区"
================================================================================

【生活类比】

购物车就像你逛超市时推的小车：
- 往车里放商品（cart_add_item）
- 从车里拿走商品（cart_remove_item）
- 算算车里东西一共多少钱（cart_calculate_subtotal）
- 买完了清空购物车（cart_clear）

【为什么需要购物车？】

在"扫码→计算折扣→结账"这个流程中，购物车是中间环节：
1. 扫码把商品加入购物车
2. 促销系统遍历购物车计算折扣
3. 结账时把购物车内容转为销售明细

购物车中的每个商品都带着折扣信息：
- original_price：原价
- final_price：折后价
- discount_amount：省了多少钱

cart_add_item() 会自动调用促销计算函数，所以商品一加入购物车就已经有了折扣价。


================================================================================
第四关：套装商品 —— 组合卖比单卖更划算
================================================================================

【生活类比：零食大礼包】

超市里经常有"大礼包"：3包薯片 + 2瓶饮料 + 1盒饼干，打包价29.9元。
如果单买要40多，打包买便宜很多。

这就是套装商品（ProductCombo）：
- 套装有自己的条形码（扫码枪扫到的是套装，不是单品）
- 套装由多个子商品按比例组成
- 套装有独立的售价

【核心函数详解】

1. create_combo() / add_combo_item() —— 创建套装和添加子商品
   比如创建"零食大礼包"，然后添加：薯片×3、饮料×2、饼干×1。

2. find_combo_by_barcode(条码) —— 通过条码哈希表查找套装
   扫码枪扫到条码后，先查是不是套装条码。

3. check_combo_stock(套装, 数量) —— 检查库存
   要卖5个大礼包，检查：薯片够不够15包？饮料够不够10瓶？饼干够不够5盒？

4. deduct_combo_stock(套装, 数量) —— 扣减库存
   卖了1个大礼包：薯片库存-3，饮料库存-2，饼干库存-1。

5. rollback_combo_stock(套装, 数量) —— 回滚库存
   顾客退货了，把库存加回去。


================================================================================
第五关：批次管理 —— 先进先出，防止过期
================================================================================

【生活类比：牛奶的保质期】

仓库里有三批牛奶：
- 批次A：5月1日到货，保质期到5月15日
- 批次B：5月5日到货，保质期到5月20日
- 批次C：5月10日到货，保质期到5月25日

卖的时候应该先卖哪批？当然是先卖最早到货的（批次A），因为它快过期了。
这就是"先进先出"（FIFO = First In, First Out）。

【批号的生成规则】

批号格式：YYMMDD + 3位序号
例如：240518001 表示2024年5月18日的第1批货

【核心函数详解】

1. create_batch() —— 创建批次
   记录：批号、商品ID、数量、生产日期、保质期天数、供应商。
   按收货日期排序插入链表（最早的排前面）。

2. deduct_batch_stock(商品ID, 数量) —— FIFO扣减
   从链表头开始（最早的批次），先扣批次A，扣完了再扣批次B，以此类推。

3. check_expiring_batches() —— 检查即将过期的批次
   找出30天内要过期的商品，提醒尽快处理。


================================================================================
第六关：储值卡 —— 预付费会员卡
================================================================================

【生活类比：理发店的充值卡】

你去理发店，充500送50。以后每次理发直接刷卡扣钱，不用付现金。
储值卡就是这个东西。

【储值卡的特点】

- 有卡号（格式：VC + 日期 + 6位随机数，如 VC240518123456）
- 有余额（充了多少、花了多少）
- 有支付密码（用SHA-256加密存储，和员工密码一样的安全级别）
- 有效期1年
- 可以绑定会员（享受会员折扣的同时用储值卡付款）

【核心函数详解】

1. create_vip_card(密码) —— 创建储值卡
   生成卡号，设置支付密码的哈希值，初始余额为0。

2. recharge_vip_card(卡号, 金额, 操作人) —— 充值
   余额 += 充值金额。记录交易日志。

3. consume_vip_card(卡号, 金额, 操作人) —— 消费
   检查余额够不够 → 余额 -= 消费金额 → 记录交易日志。

4. refund_vip_card(卡号, 金额, 操作人) —— 退款
   余额 += 退款金额。记录交易日志。

5. verify_vip_card_password(卡号, 密码) —— 验证支付密码
   用SHA-256加密输入的密码，和存储的哈希值对比。

6. bind_vip_card_member(卡号, 会员ID) —— 绑定会员
   把储值卡和会员关联起来，这样刷卡消费时能同时享受会员折扣。

7. query_vip_card_transactions(卡号) —— 查询交易记录
   显示充值、消费、退款的所有记录。


================================================================================
第七关：各子模块之间的关系
================================================================================

【协作关系图】

会员 ←→ 促销：促销计算时，需要查会员等级来决定折扣率
会员 ←→ 储值卡：储值卡可以绑定会员，消费时同时享受会员权益
促销 → 购物车：购物车添加商品时，自动计算促销折扣
套装 → 销售：销售时如果是套装，走套装专用的库存扣减流程
批次 → 销售：销售扣库存时，按FIFO从最早批次扣

【与外部模块的接口】

marketing.c 被以下模块调用：
- sale.c 调用 apply_promotions() 计算折扣、add_points() 增加积分
- sale.c 调用 deduct_combo_stock() 扣减套装库存
- main.c 的各菜单函数调用各种 CRUD 函数

marketing.c 调用以下外部模块：
- supermarket.c 的 find_product_by_id() 查商品信息
- supermarket.c 的 update_product() 更新商品信息

================================================================================
总结：第三部分的核心要点
================================================================================

1. 会员体系：手机号是唯一标识，积分用阶梯制度鼓励大额消费，等级随累计消费自动升级
2. 促销系统：支持5种促销类型，通过优先级和有效期管理，支持折扣叠加
3. 购物车：连接"扫码"和"结账"的中间层，添加商品时自动计算折扣
4. 套装商品：组合销售，有独立条码和售价，库存扣减按比例分配到子商品
5. 批次管理：FIFO先进先出，防止商品过期浪费
6. 储值卡：预付费卡，有密码保护，可绑定会员

记住一句话：会员让人"想来"，促销让人"多买"，套装让人"买套"，储值卡让人"预付"——四种手段，一个目标：提高销售额。
